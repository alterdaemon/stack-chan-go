# OpenAI settings in the web panel (R6)

Release impact: minor.

The web settings panel adds an OpenAI section between AI and MCP Server, with a backend Model field and a Thinking effort selector. Initial values come from the device's saved preferences or GPT-Live configuration. The integrated host defaults remain unchanged.

Both preferences apply on the next GPT-Live start and persist across restarts. AI token, context, voice model and the device GUI are unchanged. Update the web panel as well as the firmware to use the fields.
