# stackchan-community-mod 2.0.1-r1

Release impact: minor.

Integrate the GPT-Live MOD and drawer action into CoreS3 firmware. Read saved AI token, context and volume at session start. Use gpt-live-1 with gpt-6-luna/low, marin, brief Polish instructions and default volume 0.1, without tools.

Fork base: [stack-chan/stack-chan v2.0.1](https://github.com/stack-chan/stack-chan/tree/v2.0.1), commit `6a8f7553610e5d91770901e76fd93a0c50cfd970`.

Restored from archived source patch and matching integration archive. Revision product metadata and tag naming were assigned retrospectively; the original binaries were not rebuilt or relabeled. Release validation and the workflow were updated retrospectively to accept revision tags as prereleases.
