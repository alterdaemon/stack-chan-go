# stackchan-community-mod 2.0.1-r10

Release impact: minor.

Fork of [stack-chan/stack-chan v2.0.1](https://github.com/stack-chan/stack-chan/tree/v2.0.1).
OpenAI Settings adds Voice, Pitch and Style, applied on the next GPT-Live session.
Pitch is local Sonic processing; Style adds delivery instructions to the model.

The R10 amendment moves full-duplex AEC out of the priority-20 audio clock into
a background task below the UI priority. The audio clock queues paired microphone
and playback-reference frames without waiting. This addresses the reported menu
lag with Voice interruption On; responsiveness on the physical robot still needs
verification with the updated images.

Product metadata and release validation now use numbered fork versions. Fork revisions
are marked as prereleases and do not replace the stable Latest release.
The local history retains upstream commits and separates revisions R1–R10 with
English commits and version tags.

See [the fork changelog and installation commands](../../CHANGELOG-MOD.md) and
[R10 behavior, validation and hardware limits](./gpt-live-voice-r10.md).
